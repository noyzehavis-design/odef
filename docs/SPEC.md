# אפיון: עודף (ODEF), אפליקציית תזרים משפחתית

Nov 13, 2026 · @Noy Zehavi

## תקציר

עודף (ODEF) היא אפליקציית PWA בעברית (RTL), כהה כברירת מחדל, שמושכת כל בוקר את התנועות מהבנקים ומהכרטיסים דרך ה-API של Financy, שומרת אותן ב-Supabase, מזהה חריגות ושולחת פוש. העדכון יומי ולא בזמן אמת, והתחושה ה'חיה' מגיעה מהסטטוס, מהאייקונים ומההתראות.

**מה Financy נותן ומה לא** (נבדק מול [התיעוד](https://docs-financy.open-finance.ai), נובמבר 2026):

| נושא | מצב |
| --- | --- |
| בנקים | פועלים, לאומי, דיסקונט, מזרחי, הבינלאומי, יהב, פפר |
| כרטיסי אשראי | ישראכרט, מקס, כאל, כולל תשלומים (installments) |
| ארנקים | ביט (יתרה ותנועות) |
| ניירות ערך | יש אחזקות |
| פנסיה, גמל, השתלמות (הפניקס וכו') | לא נתמך. עדכון ידני או העלאת דוח PDF |
| היסטוריה | עד 12 חודשים אחורה |
| גישה מהשרת | REST API עם OAuth (clientId, clientSecret), נדרש מסלול Starter, כ-₪49 לחודש |
| חיבור בנק חדש | רק דרך הממשק של Financy, לא מתוך האפליקציה |
| רענון | אוטומטי פעם ביום בבוקר (אפשר להוסיף עד 4 בהגדרות), רענון יזום עולה 20 קרדיטים |
| Webhooks לתנועות | אין, לכן משיכה מתוזמנת (cron) |

**האם לבנות אחרת?** לא, הכיוון נכון: Next.js על Vercel ו-Supabase. שני שינויים קטנים שאני ממליץ עליהם: להשתמש ב-REST API במקום ב-MCP (MCP מתאים לצ'אט ולא לאפליקציה), ולבנות קודם עם נתוני דמו כדי לעצב את כל המסכים לפני שמשלמים על ה-API.

**Financy מול RiseUp.** לאפליקציה שרצה על שרת מומלץ Financy. ל-RiseUp יש [MCP רשמי](https://github.com/riseup-oss/mcp), עם קטגוריזציה טובה והשוואה למשפחות דומות, אבל הוא מיועד לעבודה מקומית מול צ'אט.

|  | Financy | RiseUp |
| --- | --- | --- |
| גישה משרת | REST API מתועד עם OAuth, בלי חידוש ידני | טוקן אישי שפג כברירת מחדל אחרי 30 יום, גרסה 0.x |
| היסטוריה | תנועות עד 12 חודשים | תנועות, ויתרות עד 90 יום אחורה |
| מעבר לתנועות | ניירות ערך | משכנתא, השוואה למשפחות דומות |
| פנסיה וחיסכון | לא | לא |
| מחיר | כ-₪49 לחודש (Starter) | מנוי RiseUp, בערך באותו מחיר (לא אומת) |

טיפ: ב-Financy אפשר לפתוח חשבון חינמי, לחבר את הבנקים ולנסות את הנתונים דרך ה-MCP ב-Claude. רק כשמגיעים לשלב חיבור האפליקציה צריך לשדרג ל-Starter.

כל הסודות (מפתחות Financy ו-Claude) נמצאים רק בשרת, והטלפון קורא רק מ-Supabase. לכן האפליקציה נפתחת מהר גם כשהבנק לא זמין. העלות החודשית הצפויה היא כ-₪49 ל-Financy, ועוד כמה שקלים ל-Claude API. Vercel ו-Supabase נכנסים במסלול החינמי שלהם בשימוש משפחתי (הערכה).

## שפה עיצובית

הרפרנסים משמשים ככיוון בלבד: מספרים גדולים ודקים, כרטיסים רכים ומעוגלים, הרבה אוויר ומעט צבעים עם משמעות. המראה עצמו מקורי.

- **כהה כברירת מחדל.** רקע #0E0F13, כרטיסים #17191F עם קו מתאר דק, טקסט באוף-וויט. בהיר ניתן לבחירה, וגם מצב מערכת.
- **צבע מותג אחד**, למשל סגול-חשמל #7C6CFF, לכפתורים ולטאב פעיל.
- **צבעי מצב** עקביים: ירוק-מנטה להכנסה ומצב טוב, כתום לאזהרה, אדמדם לחריגה. לכל קטגוריה צבע קבוע (עד 8).
- **טיפוגרפיה:** פונט עברי שתומך משקלים דקים, כמו Rubik או Heebo. סכומים במשקל 300 ובגודל 40–56, עם ספרות ברוחב קבוע (tabular-nums). סכומים מוצגים תמיד LTR בתוך מסך RTL.
- **כרטיסים:** עיגול 20–24px, בלי צללים כבדים, רווח פנימי נדיב.
- **תנועה:** מספרים ש'רצים' לערך בכניסה, גרפים שנבנים מלמטה, מעברי מסך קצרים. מכבד את הגדרת 'הפחתת תנועה' של המכשיר.

**טון: צעיר, קליל וכייפי.** האפליקציה מדברת כמו חבר שמבין בכסף, לא כמו בנק.

- **כתיבה:** קצרה, בגוף שני ובלשון דיבור. למשל 'החודש הולך פצצה 💪 נשארו ₪3,200' במקום 'יתרת התקציב הנותרת'. אזהרות ברורות אבל לא מלחיצות: 'נתפס חיוב כפול בשופרסל, שווה בדיקה'. בלי מונחים בנקאיים כמו 'יתרת זכות'.
- **צבע וצורה:** צבעי קטגוריות עזים ושמחים על רקע כהה, פינות מעוגלות מאוד, ואימוג'י אחד קטן שמייצג כל קטגוריה (🛒 🍕 ⛽).
- **UX משחקי במידה:** רצף ימים בתקציב, קונפטי כשמגיעים ליעד, גרירה של תנועה לצד לשינוי קטגוריה, ומצבים ריקים עם הומור ('אפס תנועות היום. שקט מופתי').
- **הגבול:** בחריגה אמיתית או בחיוב חשוד הטון נעשה ענייני, בלי בדיחות.

**אייקונים חיים.** סט אחד של אייקוני קו (Lucide), ומעליהם אנימציות Lottie קטנות במקומות שמספרים סיפור:

| --- | --- | --- |
| החודש מתנהל טוב | עלה / שמש | נשימה איטית |
| מתקרבים לתקרה (80%) | מד דלק עולה | מחוג שנע לכתום |

## העיקרון: לולאת שיפור

האפליקציה בנויה סביב שני מספרים, וכל השאר משרת אותם. המטרה היא שתפתחו רק אותה ולא את אפליקציית הבנק. [דגם לחיץ](https://claude.ai/artifact/1a3Fy5yvfVvfG7RVz4xfmb) מראה איך זה נראה.

- **אפשר להוציא היום:** ההכנסה החודשית, פחות ההוצאות הקבועות, פחות ההפרשות ליעדים, פחות מה שכבר יצא, חלקי הימים שנשארו בחודש. מוצג גם הסכום עד סוף השבוע.
- **שיעור חיסכון:** החלק מההכנסה שנשאר בסוף החודש, עם מגמה לאורך חצי שנה. זה המדד שאומר אם אתם משתפרים.
- **תור פעולות אחד:** התראות, טיפים, 'שווה את זה?' ורעיונות להכניס יותר נכנסים לתור אחד. מסך הבית מציג רק את הפעולה החשובה ביותר, וכשסוגרים אותה מגיעה הבאה.
- **יעדים והפרשות:** לכל יעד יש סכום ותאריך, והאפליקציה מחשבת כמה להפריש בחודש. הוצאות שנתיות צפויות מטופלות באותה דרך. ביום המשכורת מוצעת העברה ליעדים לפני שמוציאים.
- **סיכום חודשי של 5 דקות:** ב-1 בחודש, ארבעה מסכים מלאים: כמה נשאר, מה השתפר, דבר אחד לחודש הבא, ולאן הולך העודף.
- **להכניס יותר:** תזכורות לבדיקה, לא ייעוץ: כסף בעו"ש בלי ריבית מעל כרית הביטחון, עמלות בנק, דמי ניהול בקופות, החזר מס שנתי.
- **חשיפה הדרגתית:** בשבוע הראשון רואים רק את הדשבורד והתנועות. יעדים והסיכום החודשי מוצעים אחרי חודש של נתונים. לא נוסף אף טאב מעבר לארבעה.

## ניווט ומסכים

בטלפון יש סרגל צף בתחתית המסך עם ארבעה טאבים: **בית · תנועות · תובנות · חסכונות**, כשהטאב הפעיל מתרחב לכפתור עם טקסט. הסדר הוא מימין לשמאל. בדסקטופ אותם טאבים עוברים לתפריט צד צר מימין, והתוכן מוצג ברשת של 2–3 עמודות. פעמון ההתראות והאווטאר (שמוביל להגדרות) נמצאים בראש מסך הבית. מתחתיהם יש בורר חשבונות קבוע של צ'יפים: משק בית (ברירת מחדל) · משותף · נוי · אשתי. הבחירה מסננת את כל המסכים, וכל כרטיס אשראי משויך לאחד מהם. במצב 'משק בית', העברות בין החשבונות שלכם ותשלום חשבון האשראי מהבנק מנוטרלים, כדי שלא ייספרו פעמיים. המשתמש הוא רק אתה כרגע, והמבנה מוכן להוספת משתמשת שנייה בהמשך.

## התראות ותובנות

ההתראות נבנות מכללים קבועים בקוד אחרי כל סנכרון. פעם בשבוע Claude כותב מהן סיכום קצר בעברית טבעית. יש שלוש רמות דחיפות: אדום נשלח כפוש מיידי, כתום נכנס לסיכום הבוקר, וכחול מופיע רק בפיד.

**תובנות (סיכום שבועי ופיד):** מה עלה ומה ירד מול החודש שעבר, הסוחר שהכי גדל, כמה הולך על מנויים בשנה, כמה תשלומים עוד פתוחים ומתי הם נגמרים, והשוואה של אותו חודש בשנה שעברה.

## פיצ'רים מוצעים

**מנוע טיפים לחיסכון** הוא החלק שביקשת. כללים פשוטים מזהים הזדמנות, ו-Claude מנסח את הטיפ עם המספרים שלכם:

- הכנסה גבוהה מהרגיל ובסוף החודש נשאר עודף: הצעה להעביר X לחיסכון או להגדיל הוראת קבע.
- עודף קבוע בעו"ש שלושה חודשים ברצף, מעבר לכרית ביטחון של 3–6 חודשי הוצאות: הצעה לפקדון, קרן כספית או גמל להשקעה.
- סוף שנה: תזכורת להפקיד להשתלמות עד התקרה המוטבת, ולהפקדה שמזכה בזיכוי מס בפנסיה אם רלוונטי.
- חיסכון לכל ילד: בדיקה שההפקדה הכפולה מקצבת הילדים פעילה.
- מנוי שלא נוצל 60 יום, או שני מנויים דומים: הצעה לבטל וחישוב החיסכון השנתי.

ספי ההפקדה וההטבות משתנים כל שנה, לכן הם נשמרים בטבלת הגדרות שמתעדכנת פעם בשנה ולא קבועים בקוד. זה לא ייעוץ פנסיוני, והאפליקציה תציין זאת.

## פרומפטים ל-Claude Code

תשעה שלבים (כולל 2.5), וכל אחד מהם בסשן נפרד. העיצוב עצמו בידיים של Claude Code: האפיון מגדיר מה רואים ואת הטון, והוא מעצב משהו יפה ומקצועי משלו. לפני שמתחילים, שמור את המסמך הזה בריפו כ-`docs/SPEC.md`. בכל שלב, תן ל-Claude Code לתכנן קודם (Plan mode), אשר את התוכנית, ובדוק בטלפון לפני שעוברים לשלב הבא. שלבים 1–2 עובדים על נתוני דמו, כך שאפשר להתחיל עוד לפני שמשלמים ל-Financy.

**שלב 0: שלד הפרויקט**

```text
קרא את docs/SPEC.md. צור פרויקט Next.js (App Router, TypeScript, Tailwind, shadcn/ui) לאפליקציית תזרים משפחתית בעברית. שם האפליקציה: 'עודף', ובאנגלית ODEF (שם הריפו, ה-manifest והדומיין: odef). השם מופיע במסך הכניסה, ב-manifest ובכותרת הדפדפן. השאר מקום ללוגו ולאייקונים שאספק בנפרד (public/icons), ובינתיים השתמש בסימן זמני.
- כל האפליקציה ב-<html lang="he" dir="rtl">, פונט Rubik מ-next/font, סכומים תמיד עם tabular-nums ו-dir="ltr", פורמט ₪ עם Intl.NumberFormat('he-IL').
- מצב כהה כברירת מחדל (next-themes), עם מתג לבהיר ולמצב מערכת. כל הצבעים כטוקנים ב-CSS variables לפי פרק 'שפה עיצובית' ב-SPEC.
- PWA: manifest בעברית, אייקונים, service worker (Serwist), התקנה למסך הבית באייפון ובאנדרואיד.
- Supabase Auth (Magic Link + Google), עם allowlist של מיילים מ-env. כל הנתיבים מוגנים.
- שלד ניווט: סרגל תחתון צף בטלפון ותפריט צד בדסקטופ (בית, תנועות, תובנות, חסכונות), עם דפים ריקים.
- צור CLAUDE.md עם כללי הפרויקט (RTL, עברית, טוקנים, סודות רק בשרת, והטון: צעיר, קליל וכייפי בעיצוב, בכתיבה וב-UX לפי פרק 'טון' ב-SPEC, כל הטקסטים בקובץ lib/copy.ts אחד) ו-.env.example. הכן ל-deploy ב-Vercel.
```
